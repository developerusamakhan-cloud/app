# Nabia Khan brand kit

## Files

| File | Use it for |
| --- | --- |
| `logo.svg` / `logo.png` | Main logo (icon + name) on light backgrounds: invoices, proposals, email signature, documents |
| `logo-white.svg` / `logo-white.png` | Main logo on dark or photo backgrounds |
| `wordmark.svg` / `wordmark.png` | Name only, when the icon is already shown nearby |
| `wordmark-white.svg` / `wordmark-white.png` | Name only on dark backgrounds |
| `logo-mark.svg` / `logo-mark.png` | The "N" icon (dark). App icons, stickers, small spaces |
| `logo-mark-white.svg` / `logo-mark-white.png` | The "N" icon (white) for dark backgrounds |
| `social-avatar.png` | Profile picture for Fiverr, Upwork, LinkedIn, Instagram, WhatsApp Business, Google Business (1080 x 1080) |
| `og-image.png` | Share image used when the website is shared (1200 x 630). The theme adds it automatically |

SVG files scale to any size without losing quality (use them for print and design tools). PNG files have a transparent background.

The favicon set (browser tab, iPhone and Android icons) is in `../favicon`.

## Colours

| Name | Hex |
| --- | --- |
| Ink (text, dark backgrounds) | `#1A1433` |
| Violet (main) | `#7C3AED` |
| Pink (accent) | `#EC4899` |
| Gold (highlight) | `#FBBF24` |
| Lilac (on dark) | `#B9A4FF` |
| Soft background | `#FBFAFF` |

Gradient: Violet `#7C3AED` to Pink `#EC4899` (on light), Lilac `#B9A4FF` to Gold `#FBBF24` (on dark).

## Fonts

* Headings and logo: **Plus Jakarta Sans**, ExtraBold 800
* Text: **Inter**, Regular 400 and Semibold 600

Both are free Google Fonts (licences in `../fonts`).

## Rules

* Keep space around the logo at least the height of the "N" icon's dot.
* Do not stretch, recolour or add effects to the logo. Use the white version on dark backgrounds.
