A simple, light one-page theme that explains what the AI chatbot can and cannot do, with a live demo.

== Description ==

One page with these sections: features, how it works, what it can and cannot do, question buttons that open the chat, and common questions. Pair it with the AI Site Assistant plugin.

The same text is saved into the Home page, so the chatbot learns what visitors read. After activating the theme, run the website scan in the chatbot plugin.

Front page heading, intro and accent colour: Appearance, Customize, Chatbot demo.
